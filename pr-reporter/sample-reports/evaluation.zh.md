# TestPilot F：中文验收评估报告

## 一、评估结论与范围

本次固定验收标准全部通过。结果来自已保存的本地运行记录，不是新的测试运行，也不代表真实项目准确率。

- 场景：6 个合成验收场景。
- 参与准确性统计：5 个，其中 3 个有缺口、2 个为对照。
- 未知标签：1 个，排除在准确性统计之外。
- 预测阈值：缺口分数 ≥ 20。
- 重复次数：每场景 5 次，共 30 次耗时采样。
- 评估合同：`f-acceptance-v1`。

## 二、比较对象

比较对象是“只要存在历史相关测试，就认为足够”的**覆盖存在性启发式**。它从测试映射报告计算，不能检查断言是否能发现行为变化。

这不是 testmon 原生的缺口预测功能。testmon 用于选择测试，本身不预测断言缺口；不能将本表表述为“两个原生缺口检测器的真实项目准确率比较”。

| 指标 | TestPilot | 覆盖存在性启发式 |
| --- | --- | --- |
| 精确率 | 100% | 不适用（没有预测阳性） |
| 召回率 | 100% | 0% |
| 特异度 | 100% | 100% |

| 混淆矩阵 | TestPilot | 覆盖存在性启发式 |
| --- | --- | --- |
| 正确报告缺口（TP） | 3 | 0 |

## 三、逐场景结果

| 场景 | 预设标签 | 实际输出 | 平均耗时 |
| --- | --- | --- | --- |
| 精度变化，只有整数断言 | 存在潜在缺口 | 报告潜在缺口 | 4.111 ms |
| 异常变化缺少验证 | 存在潜在缺口 | 报告潜在缺口 | 0.885 ms |
| 边界变化缺少断言 | 存在潜在缺口 | 报告潜在缺口 | 0.968 ms |
| 新增分支有相关断言证据 | 对照：不应报告缺口 | 未报告潜在缺口 | 0.930 ms |
| 仅文档变化 | 对照：不应报告缺口 | 未报告潜在缺口 | 0.814 ms |
| 映射无法解析，真实标签未知 | 未知（不参与准确性统计） | 报告潜在缺口 | 0.888 ms |

“映射无法解析”场景的真实标签未知。系统虽给出潜在缺口提示，但应同时展示不确定性；不能把该预测当成已证实的正确检测。
